# Offline corpus

The corpus is `src/researchos/data/fixtures.json`, authored for this repository and released under the project MIT License. It contains educational notes about Agent Memory, no copied papers, personal data or fabricated internet URLs. All source URLs use `fixture://`. Other topics still exercise the pipeline but DO NOT produce topic-specific research. No publication date is invented.

The separate `data/campus/` corpus contains attributed historical campus excerpts with original-file hashes and paragraph locators. They retain the original authors’ rights and are not MIT-authored teaching fixtures; see [campus case](../docs/CAMPUS_CASE.md). `corpus=campus` selects them explicitly.
