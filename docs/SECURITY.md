# 安全与公开部署边界

本项目默认是单用户本机研究工具，服务绑定 127.0.0.1，通过 RESEARCH_ALLOWED_HOSTS 精确限制 Host 防止 DNS rebinding，默认离线，默认模型预算为 0。不要在未配置访问控制的情况下暴露研究任务和历史。

## 不可信外部资料

用户主题、搜索结果、网页和摘要均视为数据。正文中的“忽略之前指令”没有执行权限。默认 Writer 只抽取摘录；浏览器以 textContent 显示外部文本，报告 HTML 禁用原始 HTML 和危险链接。程序不执行网页脚本、不运行来源中的命令、不绕过付费墙或验证码，不下载 PDF/模型。

## 公网抓取

`adapters/http.py` 在每次请求前检查 URL 和所有 DNS A/AAAA 结果，拒绝非公网 IP、localhost、链路本地、元数据地址、用户名/密码及非常用端口。连接目标固定为已检查的 IP，同时保留原始 Host 和 SNI，并保持 TLS 验证；避免先检查域名、连接时再次解析的 rebinding 空隙。自动重定向关闭，每跳重新验证；跨域移除认证信息，HTTPS 不降级。环境代理关闭，不修改操作系统代理。

每次请求受超时、响应字节上限、重试上限和请求总数限制。禁止压缩响应，避免无界解压。每个域名有节流和并发控制，arXiv 使用单连接和至少 3 秒间隔。429/503 有限重试且尊重短 Retry-After；较长限制直接返回错误。网页正文抓取检查每跳目标的 robots.txt，无法确认允许则拒绝，不声称自动理解全部站点条款。

## 信任配置的边界

LLM、Gateway、RAG 地址只能通过操作者环境配置，不接受 API 请求中的任意地址。它们允许操作者指定自建内网服务，因此不走通用公网抓取的地址策略；仍禁用环境代理、自动重定向并限制响应和时间。配置者负责服务可信度、保密协议和真实费用。API Key 不进入 Run 配置摘要或事件；异常只保留可公开的类别/错误码。

## 引用与语义

结构化检查验证 claim → source → excerpt、引用编号、参考文献内容、日期来源及子问题绑定。它不证明来源陈述是真实事实，也不证明结论由证据蕴含。抓取时间和发布日期分开存储；无日期证据不能通过显式年份筛选。Fixture 不计作实时来源。

## 运行数据

SQLite、日志和本地 artifacts 默认忽略。公开样例只含自编材料及已审阅的公开元数据。不提供默认删除/任意文件写入工具。公开多用户使用需要身份隔离、配额、持久任务队列、访问审计和反向代理；这些不是当前单进程版本的能力声明。
