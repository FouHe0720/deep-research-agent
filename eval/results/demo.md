## 问题定义

Agent Memory 的工作记忆、情节记忆与语义记忆如何区分？

## 核心发现

资料仅覆盖 Agent Memory 教学案例；其它主题只演示程序流程，结论待验证。

- 来源摘录: Agent Memory 可按工作记忆、情节记忆和语义记忆组织。工作记忆保存当前任务状态，情节记忆保留交互过程，语义记忆保存可检索知识。这是本项目编写的教学简化，不是文献综述结论。 [1]

- 来源摘录: 知识条目应保存来源地址、抓取时间和原文摘录。抓取时间不等于发表日期；缺少来源日期时应保留空值，不应根据抓取日期猜测论文年份。 [2]

- 来源摘录: 一个最小可审计实现可用 SQLite 保存来源与摘录，用 FTS5 检索相关片段，再将片段标识传入写作步骤。向量索引是可选组件，不能替代来源和引用绑定。 [3]

- 来源摘录: 固定输入、固定资料与确定性写作可以验证研究流水线的程序行为。离线回归能够发现引用编号或导出故障，但不能代表真实互联网检索质量。 [4]

- 来源摘录: 长期保存可能增加隐私暴露和过期知识风险；只保存短期上下文可能丢失跨任务信息。需要显式保留策略、删除能力以及依据任务评估的检索指标。此材料没有比较任何真实产品的性能。 [5]

- 来源摘录: 引用存在、摘录非空和编号一致可以用程序检查。主张是否由证据充分支持仍需语义判断和人工复核；自动检查通过并不意味着消除了所有幻觉。 [6]
